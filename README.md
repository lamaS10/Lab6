# Lab 6

This repository contains two parts for Lab 6:

## 1. Employee Management System
A Spring Boot application for managing employees.

### Features
- Get all employees
- Add a new employee
- Update employee information
- Delete an employee
- Search employees by position
- Search employees by age range
- Apply for annual leave
- Get employees with no annual leave balance
- Promote an employee

### Extra Features
- Apply for multiple annual leave days

---

## 2. Crunchyroll Documentation
A documentation analysis of the Crunchyroll platform.

The documentation includes:
- Overview of the system
- UML Diagram
- User Model
- Anime Model
- Episode Model
- Watchlist Model
- Subscription Model
- Payment Model
- Validation requirements for each model

The documentation is available as a PDF inside the `CrunchyrollDocumentation` folder.
